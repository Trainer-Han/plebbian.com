    About

    A builder who actually ships.

    How I work

    Plebbian started as a side project and turned into a place to build properly. I work mostly in TypeScript, React and Node, with a healthy amount of Python and infrastructure glue holding it together.

    Good code matters to me. So does accessibility, sane API design and making the UI feel right. I try hard not to over-engineer things.

    100% Open source

    Everything public and readable, mistakes included.

    Right now

    Community tooling, backend performance, and AI features that are genuinely worth having rather than bolted on.

    What I care about

    Software that stays fast under real use, interfaces that work with a keyboard and a screen reader, and APIs you can understand without a diagram. Nothing here is novel — it is just done on purpose.
