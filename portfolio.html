    About

    A builder who actually ships.

    AI-native, and still working it out

    I build with AI in the loop by default — planning, writing, reviewing. It is not a feature bolted on to sound current, and it is not a shortcut around knowing how the thing works. It is simply how the work gets made here.

    The exploring is the honest half. I am still learning where a model earns its place, where it quietly makes things worse, and how much to trust something that sounds equally certain either way. So far the answer is that it is very good company and a poor authority — it drafts fast, and everything still gets read before it ships.

    AI-assisted Reviewed by hand Still learning

    How I work

    Plebbian started as a side project and turned into a place to build properly. I work mostly in TypeScript, React and Node, with a healthy amount of Python and infrastructure glue holding it together.

    Good code matters to me. So does accessibility, sane API design and making the UI feel right. I try hard not to over-engineer things.

    100% Open source

    Everything public and readable, mistakes included.

    Right now

    Community tooling, backend performance, and AI features that are genuinely worth having rather than bolted on.

    What I care about

    Software that stays fast under real use, interfaces that work with a keyboard and a screen reader, and APIs you can understand without a diagram. Nothing here is novel — it is just done on purpose.

    Featured

    syntaxx.lol, the big one.

    The largest thing I have worked on — a Discord bot running across community servers, plus the desktop app used to support them. My part in it closed in September 2026; the full write-up is kept in the archive.

    Moderation and automod, warns and infractions, levelling and economy, private join-to-create voice channels with an owner control panel, and text “calls” relayed between servers.

    Alongside the bot sits a PySide6 desktop dashboard. It lets a developer manage a server’s settings remotely — but only after that server’s owner grants consent over DM, and every change it makes is written to a log the owner is sent when access is revoked.
